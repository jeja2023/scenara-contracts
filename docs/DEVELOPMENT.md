# 开发规范

1. 先更新能力词典和实体词典，再修改 Schema、API 或事件。
2. 每项契约同时提供有效示例、无效测试、生产方验证和消费方兼容夹具。
3. 不得修改已发布目录。兼容新增使用次版本，不兼容变更使用主版本。
4. 运行 `python scripts/repository_contracts.py --check --against <previous-dir>` 验证生成内容、摘要和兼容性。
5. 发布包必须确定性构建并记录 SHA-256、版本、责任人和消费方升级状态。

字段命名使用英文，文档以中文为主。绝对时间使用 UTC RFC 3339，持续时间使用带单位字段。对象引用不得包含本地路径，必须绑定不可变摘要。
