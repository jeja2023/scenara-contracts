# 景枢能力词典

本词典是平台能力名称和责任仓库的事实来源。能力 ID 发布后保持稳定；具体框架或模型名称不得替代平台能力 ID。

| 中文名称 | 英文名称 | 简称 | 能力 ID | 责任仓库 | 状态 | 版本 | 内部实现映射 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 数据集 | Dataset | Dataset | `dataset` | `scenara-data` | active | 1.0.0 | 无 |
| 数据集版本 | Dataset Version | Dataset Version | `dataset_version` | `scenara-data` | active | 1.0.0 | 无 |
| 模型训练 | Model Training | Training | `model_training` | `scenara-model` | active | 1.0.0 | FastReID/PyTorch Adapter |
| 模型评估 | Model Evaluation | Evaluation | `model_evaluation` | `scenara-model` | active | 1.0.0 | Rank-1/5/10、mAP |
| 模型注册 | Model Registry | Registry | `model_registry` | `scenara-model` | active | 1.0.0 | 无 |
| 人物检测 | Person Detection | Detection | `person_detection` | `scenara` | active | 1.0.0 | 责任仓库内映射 |
| 人物重识别 | Person Re-Identification | ReID | `person_reid` | `scenara-model`、`scenara` | active | 1.0.0 | `body_reid`、`body_embedding` |
| 特征库 | Feature Store | Feature Store | `feature_store` | `scenara` | active | 1.0.0 | pgvector Provider |
| 向量检索 | Vector Search | Vector Search | `vector_search` | `scenara` | active | 1.0.0 | pgvector Provider |
| 人物检索 | Person Search | Person Search | `person_search` | `scenara` | active | 1.0.0 | 无 |

每次新增或弃用能力必须补充输入、输出、权限、事件、错误码、迁移方案和消费方兼容证据。
