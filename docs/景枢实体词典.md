# 景枢实体词典

| 中文名称 | 英文名称 | 责任仓库 | 关键约束 |
| --- | --- | --- | --- |
| 媒体 | Media | `scenara` | 生产媒体事实来源 |
| 样本 | Sample | `scenara-data` | 通过对象引用关联来源内容 |
| 数据集 | Dataset | `scenara-data` | 拥有多个不可变 Dataset Version |
| 数据集版本 | Dataset Version | `scenara-data` | 发布后不可覆盖 |
| 标注 | Annotation | `scenara-data` | 绑定样本、版本、操作者和审计 |
| 人物 | Person | `scenara` | 不等同于 Detection、Track、Feature 或 Sample |
| 轨迹 | Track | `scenara` | 绑定媒体、相机和带单位的时间轴 |
| 特征 | Feature | `scenara` | 绑定模型版本、维度、距离和 Feature Space |
| 模型 | Model | `scenara-model` | 拥有多个不可覆盖 Model Version |
| 模型版本 | Model Version | `scenara-model` | 绑定数据版本、配置、代码、环境和评估 |
| 模型制品 | Model Package | `scenara-model` | 不可变对象引用与 SHA-256 |
| 实验 | Experiment | `scenara-model` | 记录可复现配置与代码版本 |
| 训练任务 | Training Job | `scenara-model` | 状态机、日志、审计和取消语义 |
| 推理运行 | Inference Run | `scenara` | 启动时冻结模型绑定 |
| 分析结果 | Analysis Result | `scenara` | 记录模型、制品摘要和来源 |
| OCR 文本块 | OCR Text Block | `scenara` | 绑定页/帧、位置、置信度、语言和阅读顺序 |
| 行为动作 | Behavior Action | `scenara` | 绑定时间区间、动作类型、轨迹和模型来源 |
| 时序片段 | Temporal Segment | `scenara` | 开始时间必须不晚于结束时间，单位为毫秒 |
| Cosplay 角色检测 | Cosplay Detection | `scenara` | 角色与作品标签必须来自版本化标签模式 |
| 服装风格 | Clothing Style | `scenara` | 风格、子类与属性必须记录置信度和模型来源 |
| 配饰检测 | Accessory Detection | `scenara` | 配饰类别、位置和属性必须来自版本化标签模式 |
| 领域标注模式 | Domain Annotation Schema | `scenara-contracts` | Schema ID 和版本发布后不可原地变更 |
