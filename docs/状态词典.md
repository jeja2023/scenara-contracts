# 状态词典

API 和事件中的状态值使用小写。每个实体必须定义合法转换、终态、可重试状态、权限和审计动作。

- 任务：`queued`、`running`、`succeeded`/`completed`、`failed`、`cancelled`，可选 `pausing`、`paused`、`cancelling`。
- 模型发布：`candidate`/`draft`、`validating`、`validated`、`approved`、`active`、`retired`。
- 数据集版本：`draft`、`building`、`ready`/`validated`、`published`、`archived`/`retired`。

责任仓库可以采用更完整状态机，但跨仓库输出必须使用已登记状态或显式版本化映射。
