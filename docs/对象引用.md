# 对象引用

跨仓库文件、模型、数据集、样本、结果和证据使用 Provider 中立的不可变对象引用：

```yaml
bucket: scenara-models
key: person-reid/1.0.0/model.onnx
version: "provider-version"
checksum: sha256:0123456789abcdef
size_bytes: 104857600
content_type: application/octet-stream
```

引用必须有非空 bucket/key、带算法前缀的摘要、读取时重新校验和按组织/项目/服务账号授权。不得传递 `/mnt/data`、`C:\\models` 或其他本地路径，Provider、桶名和访问地址不得成为业务判断条件。
