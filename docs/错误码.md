# 错误码

统一错误结构：

```json
{
  "schema_version": "1.0",
  "request_id": "req_example",
  "error": {
    "code": "MODEL_NOT_FOUND",
    "message": "模型不存在",
    "details": {}
  }
}
```

初始分类保留 `AUTH_*`、`PERMISSION_*`、`DATASET_*`、`ANNOTATION_*`、`TRAINING_*`、`MODEL_*`、`CONTRACT_*`、`OBJECT_*` 和 `INTERNAL_*` 命名空间。具体错误码必须在对应 API/事件发布前登记，未知异常映射为已登记服务端错误码并保留 `request_id`，不得返回数据库异常、路径、密钥或堆栈。
