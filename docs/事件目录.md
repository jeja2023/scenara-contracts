# 事件目录

事件名使用小写点分形式 `<domain>.<entity-or-process>.<action>`，事件信封包含 `event_id`、`event_type`、`event_version`、`occurred_at`、`producer`、`tenant_id`、`project_id`、`request_id`、`trace_id` 和 `data`。

第一阶段登记：

- `dataset.created`
- `dataset.version.created`
- `training.started`
- `training.completed`
- `training.failed`
- `model.registered`
- `model.package.created`
- `model.released`
- `model.activated`
- `model.rollback`
- `model.deployment.changed`
- `inference.completed`
- `hard_sample.created`
- `result.available`
- `result.delta`

已发布事件采用至少一次投递，生产方使用 Outbox 或等价机制，消费方按 `event_id` 幂等。事件含义不得原地修改。
